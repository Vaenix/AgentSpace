## 复算入口

在 AgentSpace 仓库根目录运行，只需 Git、Python 3.11 或更高版本和已归档的文本，不需媒体、GPU 或模型。脚本先按 SHA-256 核对冻结文件，再从主分支可达的合并提交 `87ee601` 读取协议锁定的解析器源码，并在执行前核对 `4ebbd521…`。它对每条原文重放两种解析，并逐字段核对账本中的旧严格解码结果。无回复的可运行键必须在 `attempts.jsonl` 中有失败或中断记录。

```sh
python3 av-occurrence-study/run/participant_extension/results_1124/summarize.py \
  --output /tmp/participant-extension-replay.json
cmp av-occurrence-study/run/participant_extension/results_1124/statistics.json \
  /tmp/participant-extension-replay.json
python3 -m unittest discover -s av-occurrence-study/run/participant_extension/results_1124 -p 'test_*.py'
```

本机用 Python 3.12.0 和 3.11.7 各复算一次，输出与存档逐字节相同。离线测试覆盖状态分类、四格与转移表求和、缺失键须有日志、重复或篡改的账本行，以及运行器复用已有回复。

## 本机生成入口

先按 [冻结输入说明](../frozen_inputs/README.md) 重建 66 张帧（`--frames-root` 指向含 `frames/<题对>/` 的输出目录），再用上一批的执行环境运行。脚本在加载模型前完成全部指纹核对；`replies.jsonl` 中已有完整原文的键直接复用，不重新生成。失败的键写入 `attempts.jsonl` 并保留原因，下次以同一输入重试。`--results-dir` 默认为本目录。

```sh
/tmp/av-occurrence-mlx-venv/bin/python \
  av-occurrence-study/run/participant_extension/results_1124/run_generation.py \
  --model /path/to/checkpoint-fdcc572 --frames-root /tmp/av-participant-media/frozen-inputs
```

对本批存档重跑会复用全部 66 条回复，不加载模型。生成后已在账本副本上验证这一点，存档账本未改动。
