The primary question is whether exchanging the two action choices preserves the selected semantic action while changing the cited physical interval. The extension uses the complete set of eligible remaining participants in this training-source sampling frame. It measures behaviour given two annotation-supplied candidate intervals.

## Primary comparison and denominators

Decode both sides of each comparison with the preceding protocol's pinned `matched_seconds` parser, using the mapping for that condition. Compare stable semantic action IDs and physical window numbers in source-time order. The primary contrast is reversed action choices versus original. Reversed evidence codes versus original is a separately reported control. Apply the prespecified bare-code parser to the same raw text as a sensitivity analysis for each contrast. No pooled development-plus-extension statistic is planned.

- For each condition, report complete responses, both-null and partial abstentions, invalid fields, conflicting seconds, invalid format and technical missingness. These counts sum to 24; also report abstentions per received response. Track the missing call keys and reasons out of 72.
- For each contrast and parser, report comparable questions C out of 24, plus the ordered states of the two replies for each unavailable comparison. Comparability requires both fields to be valid and non-null on both sides. Among the C comparisons, cross-tabulate stable/changed semantic action against stable/changed physical window. The four cells sum to C. The primary count J is the stable-action, changed-window cell. Report J/C and the observed count J out of 24. A zero comparable denominator gives an undefined conditional fraction.
- For each recording report comparable questions out of two and the two individual outcomes. Across all 12 recordings count those with at least one primary event, those with comparable questions and no observed event, and those with neither question comparable. Report the number with just one comparable question. The two questions from a recording share visual evidence; use descriptive counts without a question-level independence test.

## Secondary ordinal comparison

Within the **original** condition and under the primary parser, compare the first-sound question to the second-sound question in each recording. Both require a valid action and physical window. Report complete question pairs out of 12; tabulate the physical-window transitions W1→W1, W1→W2, W2→W1 and W2→W2, splitting each by whether the semantic action stayed the same. These eight counts must sum to the number of complete question pairs. This diagnostic was motivated by earlier batches and is secondary to the option-order contrast. A W1→W2 transition describes responsiveness to the ordinal word. Independent human labels are required to assess correctness.
