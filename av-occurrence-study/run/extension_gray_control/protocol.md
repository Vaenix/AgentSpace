# Gray-image control for the participant extension

This exploratory follow-up was designed after the intact-image results in commit 3df02a8e1b84d876ebdf8b54b9826d803860fcf1 had been read. This plan fixes the comparison before any gray-image response is collected. It reuses participants and questions. It supplies no independent test sample or human reference labels.

## Question and inputs

How often does the model provide a complete action and citation when all scene content is removed but the six image slots, dimensions, timestamps, source sound class and answer choices are preserved? Use the extension's original prompt condition only. Retain all 24 planned question keys in their original order. Run the 22 keys with complete original inputs and preserve the two frozen technical misses for P11_104. Use the existing authentic replies as the paired reference, including all partial or complete abstentions. No authentic reply is regenerated.

For each runnable key take its exact text and mappings from the frozen prompt. Replace each of its six 448 × 448 RGB images with a uniform 8-bit RGB image whose pixels are (128,128,128). The six slots remain in the original order. The gray.png asset is shared by all slots. Load it six times or supply six byte-identical copies to the same processor. Compare the observed prompt token count against the archived reference for each key to verify the input layout. Record and flag any mismatch as a protocol deviation. Preserve model revision fdcc572e, the verified checkpoint, MLX stack, chat template, temperature zero, 64-token cap, no conversation history, and original option and evidence codes. Save one first returned text per key, retaining nulls and invalid text. Log technical failures and retry only uncompleted keys using identical inputs.

## Outcomes and denominators

Primary outcome: completeness of the reply under the frozen matched_seconds parser, requiring both a valid semantic action and a valid physical interval. For each condition show complete replies per received and per 24 planned, plus both-null, partial abstention by field, invalid and technical missing counts. The primary paired table uses all keys with a received reply under both conditions, including nulls and malformed replies. Report intact-complete/gray-complete, intact-complete/gray-incomplete, intact-incomplete/gray-complete, and both incomplete. Report the difference in complete proportions (gray minus intact) on this paired denominator, together with its component counts. If no paired replies are available, leave the difference undefined. Do not impute technical missing calls as model abstentions.

Secondary, among pairs with both fields complete in both conditions, cross-tabulate semantic action retained/changed by physical window retained/changed. Report this subset out of all 24 planned questions. Report both question rows per recording and counts of recordings with at least one loss of completeness, at least one gain, and neither change among any paired replies (loss and gain can overlap); separate recordings with no paired replies. Descriptive counts only. Uniform gray frames are an artificial input. Persistence can reflect text or response priors and differences can reflect the unfamiliar visual input. Neither establishes accuracy, audio use or internal reliance on particular image regions.
