# Swapping frame groups between supplied occurrences

This exploratory control was designed after reading the original extension, gray-image and joint-label results. It reuses the recordings and questions from commit `3df02a8e1b84d876ebdf8b54b9826d803860fcf1`. The question is whether the model continues to cite the same displayed interval when the two groups of real images exchange places. A secondary comparison asks whether a preserved action answer continues to cite the same group of images after it moves to the other interval.

## Analysis before seeing outputs

Use the extension's locked matched-seconds parser as primary and its bare-code parser as sensitivity. Decode each action through the original A/B map and each citation through the original printed E01/E02-to-interval map. Define the cited image group separately: under the swapped condition, the group shown at displayed interval 1 came from source interval 2 and vice versa.

Primary comparison: among questions with a valid action and cited interval in both conditions, tabulate all four combinations of same/changed semantic action and same/changed displayed interval. Report the proportion changing the displayed interval irrespective of action, with its numerator, comparable denominator and the 24 planned questions. Secondary: within action-stable comparable questions, count those retaining the original image group by citing the other displayed interval. Report undefined when the relevant denominator is zero. This contrast can show sensitivity to image placement; the timestamp mismatch and change in global viewing order limit causal interpretation. It does not measure action or temporal accuracy.

For each condition report all reply statuses and planned slots. Also tabulate both complete, original only complete, swapped only complete, neither complete among pairs with two returned texts; separate planned technical misses. Give question-level statuses and the two outcomes by recording, including recordings with no comparable question.
