# Original-input repeat on the host used for the real-frame swap

This is a repeatability diagnostic designed after the frame-swap result at cb2b9ab6. Keep the published first replies and all prior analyses intact. On the host that ran the frame-group swap, independently generate one new reply to each of the 22 runnable original-order questions. Keep both P11_104 slots missing. Use the unmodified original runner, the same model files, environment, template, image content, frame order, temperature and token cap as the archived original. Reuse the other two conditions only as skip records for the original runner. Supply no previous output to the model. Retain a fresh output directory and never rerun a returned key.

Primary endpoint is exact equality of the first and repeated raw response strings (including whitespace) out of the 22 paired texts, with 24 original-order slots planned. Compare input-token counts for every paired key. Secondary, apply both locked parser rules to both texts and compare status, semantic action and displayed interval, counting agreement in all three separately from raw-text agreement. If there is any mismatch, show its question, condition and both replies. Tabulate missing/failed slots separately. Re-evaluate all four action/interval cells against the swapped-frame replies using the new baseline and report the comparable denominator. One repeat assesses reproducibility for this host and setup; it is not an estimate across repeated seeds or devices.
