# 选项顺序与证据换窗：独立视频复测协议

冻结日期为 2026-11-24。这批只检验已有两个候选窗时，改变提示中的标签是否会改变模型报告的证据。声音类别、时间和动作候选来自 EPIC 公开训练标注。模型直接接收图像和文字；没有人工答案，行为指标不能衡量长视频检索、真实声音辨识或作答正确率。

## 视频、问题与停止条件

样本框固定为 [11 月 24 日的六项训练来源队列](../replication_1124/manifest/ranked_train_candidates.jsonl)。沿用原排序，按视频排除所有已经产生过回答的材料，同时排除原验证队列以及上批三个训练视频的参与者。每位参与者最多一个视频。本批取原排名 4、5、6，依次为 P27_101（窸窣声）、P04_121（倾倒声）、P15_02（提示音）。它们是同一筛选框中的连续留出项，选择依据是既有排名和暴露记录。序号指提供给模型的两次候选事件，全片实际先后仍待核实。

每片两问（第一、第二次），每问三个条件。名单上限固定为 3 片、6 题、18 次生成。媒体预检失败逐片记录，不从后续排名补位。推理失败只允许在同一冻结输入上重试尚无完整回复的键，保留失败记录；任何已有完整原始回复，包括全拒答或无法解析，都不重新生成。发现历史暴露则标为污染并披露，禁止事后换片或把该片写成新样本。

## 模型输入

沿用 [上一批条件构造、检查点与执行参数](../replication_1124/replicate.py)。每个物理窗三帧，取声音中点及其后动作的 25% 和 75% 时点。只要有一点超出裁片，该窗三帧全改取裁片时长的 20%、50%、80%。六帧按原片时间排序。两窗使用同一来源声类文字，动作描述仅列作两个选项。问题分别询问所给两次声音中第一或第二次结束后人物做什么。两问共享帧、选项和物理窗。

| 每题生成顺序 | 变化 | 对照时保持固定的内容 |
| --- | --- | --- |
| 原顺序 | 基准提示，平排列出图像条目和声音文字条目 | 记录各选项的语义 ID、各片段代号的实际区间 |
| 仅换选项 | A、B 对应的动作互换 | 六帧内容和顺序、证据条目及其代号 |
| 仅换片段代号 | 较早窗与较晚窗的 E01、E02 互换 | 选项、六帧内容和顺序、显示的原片秒数和证据条目顺序 |

各次独立输入，无对话历史。模型为本地 MLX 4 位 Qwen2.5-VL-7B-Instruct，修订号 `fdcc572e8b05ba9daeaf71be8c9e4267c826ff9b`，温度 0，最多 64 个生成 token。原始文字按题号和条件留存一次，所有解析共用该份回复。运行前复核冻结内容及两块权重指纹。

## 预设解析

**主分析**接受单独代号，或代号加与该条件提示完全相符的起止秒数。**严格敏感性分析**逐字沿用旧版 [decode](../infer_mlx.py)，只接受单独合法代号，并要求两个解码字段均有效才可比较。上一批的带秒数分析继续标为事后分析。本批主次顺序在看新输出前固定。

1. 读取完整 JSON 对象，允许整段包在 Markdown 代码围栏中。字段须恰为 `answer` 和 `event`。额外解释文本、非对象、缺键或多键归为格式错误。使用旧解码器相同的 JSON 装载行为。
2. 动作接受本条件大写选项字母或 JSON 的 `null`。事件接受本条件大写代号（如 `E01`）、`null`，或完整的“代号＋起止秒数”。主解析锁定为 [PR #2 的具体实现](https://github.com/Vaenix/AgentSpace/blob/f6919987b6fe3ecf9746f7d9a5d7ab1edb8db3c4/av-occurrence-study/run/infer_mlx.py) 中的 `parse_reply(..., rule="matched_seconds")`。事件字符串首尾空格可忽略，代号区分大小写，代号与数字之间至少一个空白。两端可用连字符或短破折号分隔，各端可带小写 s。用十进制数与当次提示中**显示的**起止秒数逐端比较（允许末尾零，不设容差）。两端均相等才还原为映射中的原片区间。只给秒数、嵌在自然语言里的代号均为无效字段；形式合法但端点不符单列为“代号与秒数冲突”。禁止按秒数反查另一代号、模糊匹配或人工猜答。
3. 每个输出一项互斥状态。依次判定为技术缺失、格式错误、代号与秒数冲突、无效字段、双字段弃答、只弃答动作、只弃答证据、完整有效。有合法 JSON 且其余字段合法时，才将相应的显式 `null` 计为弃答；字符串 `"null"` 归入无效字段。旧严格解析返回的 `ok` 也可能含空值，须保留弃答区分。技术缺失须能在运行日志中追踪，不能计成模型弃答。
4. 以动作语义 ID 比较动作，以按原片时间排序的物理窗 1 或 2 比较引用。即使两次输出同为 `E01`，片段代号互换时仍可能指向不同窗。

## 分母与按片汇总

主要干预为仅换选项，片段代号互换单独报告。每种解析、每种干预均与本题原顺序比较，保留两侧逐项状态。一个比较仅当两侧各有一个有效语义动作和一个有效物理窗才“可比”。主事件要求**同一题同时满足语义动作相同、物理窗改变**。

| 层级 | 固定报法 |
| --- | --- |
| 输出 | 每条件以 6 个计划输出为分母，列出上述互斥状态，合计为 6。显式弃答数为双弃答及两种部分弃答之和，同时列“弃答／实际收到回复数”。全批列已收到／18。 |
| 题目 | 每个干预列可比题数 C／6、不可比数 6−C、主事件数 J／C、动作相同数和换窗数。另列 J／6，含义仅为全体冻结题中实际观察到该事件的份额。不可比题的事件结论记缺失。 |
| 视频 | 每片每种干预列 Cᵥ／2、Jᵥ／Cᵥ、两个题号及各自结果。Cᵥ=0 记“不可判断”。Cᵥ=1 时注明仅有一问可比。 |
| 跨片 | 以全部 3 片列出“至少一问观察到事件”“有可比题且可比题中未观察到”“两问均不可比”三类片数。同时给出三片各自可比题数。两问不能作为独立视频，不做显著性检验或总体发生率推断。 |

C 或 Cᵥ 为 0 时，条件内事件比例记未定义。两侧的失败原因可能不同，按有序状态对计不可比题数，一题只计一次。例如原顺序弃答且反转后格式无效，这道题进入“弃答 × 格式无效”，继续保留在 6 题分母中。

## 离线复建与核查

```sh
python3.12 av-occurrence-study/run/confirmation_1124/prepare_inputs.py \
  --media-dir ../av-occurrence-study/run/replication_1124/review_media \
  --output /tmp/epic-holdout-rebuild/manifest
```
