# 三片独立批盲核材料就绪清单

本清单核查独立复核者能否打开 P27_101、P04_121、P15_02 的公开原片，并从 0 秒连续看到第二次候选声音及随后动作。核查对象是[冻结队列](../manifest/selected.jsonl)（SHA-256 `5d9a9158…915a5`，与[冻结记录](../manifest/provenance.json)一致）中的官方地址。核查只涉及材料能否获取、能否播放，以及声画轨是否齐全。是不是同类声音的前两次、听到什么、随后做了什么，均留给两位复核人判断。本目录不含 A/B 人工记录，也不发布视频。

核查时间为 2026-11-25（UTC 03:15–03:59），环境为 macOS 本机、curl 和 FFmpeg 8.1.2。浏览器部分用 Playwright 自带引擎。机器可读结果见 [sources.json](sources.json) 和 [browsers.json](browsers.json)。

## 结论

| 项目 | 状态 |
| --- | --- |
| 三片原片能否公开获取 | **可以**。官方地址直接返回 200，无需登录，支持字节范围请求 |
| 从 0 秒到第二次动作结束后 10 秒的声画是否完整 | **完整**。索引无断档，两轨全程解码 0 条错误 |
| 原片时间与播放器时间是否一致 | **一致**。两轨都从 0 秒开始，编辑表不平移时间，播放器读数即原片秒数 |
| 在线边下边看能否连续核查 | **在本环境不行**。单连接约 0.7–0.9 MB/s，原片码率 3.0–3.8 MB/s，实测播放速度只有实时的 0.09–0.31 倍 |
| 复核者的可行做法 | 先完整下载原片，再用本地播放器从头看。三片共 11.9 GB |
| 播放器编码支持 | P27_101、P04_121 为 HEVC，P15_02 为 H.264。WebKit 能解码三片，其他浏览器未能验证 |
| 盲核页 `review.html` 能否用于本批 | **不能直接使用**。页面内嵌的是原验证队列（修订 `35cbbebe…`，10 对），不含这三片 |
| 便携包裁片能否替代原片 | 不能用于从头连续核查。P15_02 第 2 段在动作结束前截止 |

## 在线播放的限制

原片的索引（`moov`）位于文件末尾。支持字节范围请求的播放器会先读取文件尾部，再从头播放，WebKit 的实测正是如此。只能顺序下载的工具必须下完整个文件才能播放。

用 Playwright WebKit 26.0（无界面）直接加载官方地址并静音播放，每段 30 秒：

| 原片 | 读到元数据 | 从 0 s 播放 30 s | 跳到第二次声音前 5 s | 随后播放 30 s |
| --- | --- | --- | --- | --- |
| P27_101 | 8.6 s | 前进 2.7 s（0.09 倍），缓冲到 8.6 s | 14.3 s | 前进 9.4 s（0.31 倍） |
| P04_121 | 9.2 s | 前进 2.9 s（0.10 倍），缓冲到 8.6 s | 28.3 s | 前进 8.1 s（0.27 倍） |
| P15_02 | 5.5 s | 前进 2.7 s（0.09 倍），缓冲到 6.8 s | 12.2 s | 前进 6.3 s（0.21 倍） |

服务器单连接实测约 0.7–0.9 MB/s，低于原片码率，所以在线播放会反复卡顿。按这个速度，从开头连续看到 P04_121 的第二次动作需要先接收 4.78 GB，单连接约需 1.7 小时。多连接分段下载能加快：本次 12 路并发时为 7–9 MB/s，实际接收 8.0 GB 用时约 15 分钟。网络条件不同，速度也会不同。

本环境的其他浏览器结果如下，均为环境限制，不代表原片损坏：

- Playwright Chromium 140 不含 H.264、HEVC 和 AAC 解码器，`canPlayType` 返回空，三片都报 `MEDIA_ERR_SRC_NOT_SUPPORTED`。正式版 Google Chrome 未安装，未测。
- Playwright Firefox 在 120 秒内未能启动，未测。
- 本机 Safari 未做自动测试。

P27_101、P04_121 是 HEVC 编码，复核者使用的浏览器或播放器须支持 HEVC。三片下载到本地后，FFmpeg 均能完整解码。

## 盲核页与本地材料

- **盲核页**：[`review.html`](../../../review.html) 内嵌原验证队列（修订 `35cbbebe…`，P22_03 等 10 对），不含 P27_101、P04_121、P15_02。页面的“打开原片”、片段播放和导出都只针对那 10 对。导出记录的 `queue_revision` 也不会是本批 `selected.jsonl` 的哈希。要用页面复核本批，需要另备含这三片的队列和页面；否则须改用其他记录方式。用哪种方式由维护者决定，本清单未改动页面。
- **便携包裁片**：按维护者说明，6 段裁片在本地包内，本次未获取也未核验。按[媒体清单](../manifest/media.jsonl)的起止时间，5 段覆盖对应的声音和动作结束点。P15_02 第 2 段为 384.704–397.170 s，标注动作 392.17–417.92 s 的后 20.75 s 不在段内。裁片都不从 0 秒开始，从头连续核查仍须回原片。
- **旧可用性快照**：`replication_1124/manifest/available.jsonl` 把这三对记为 `decoded: [false, false]`，那是 11 月 24 日首轮的快照。本次直接核查官方原片，三片均可获取和解码。

## 复现

在 AgentSpace 仓库根目录运行。需要 Python 3.10 或更高版本、curl 和 FFmpeg。下载的字节存放在 `--cache` 指定目录（默认在系统临时目录）的稀疏文件中，重复运行会续传。

```sh
# 头信息、文件结构、索引连续性，以及两次候选窗的解码（约 0.43 GB）
python3 av-occurrence-study/run/confirmation_1124/blind_review_readiness/check_sources.py \
  --output /tmp/blind-review-sources.json

# 另外接收 0 秒到第二次动作结束后 10 秒的全部字节，并完整解码声画两轨（约 8.7 GB）
python3 av-occurrence-study/run/confirmation_1124/blind_review_readiness/check_sources.py \
  --full --connections 12 --output /tmp/blind-review-sources.json

# 浏览器在线播放（需要 pip 安装 playwright 并下载浏览器）
python3 av-occurrence-study/run/confirmation_1124/blind_review_readiness/browser_probe.py \
  --output /tmp/blind-review-browsers.json
```

`sources.json` 由第二条命令生成，`browsers.json` 由第三条命令生成。下载速度、耗时和浏览器结果随网络变化，不能逐字节复现。文件大小、ETag、轨道、索引和解码结果应保持一致。
